# Snake Game

This is a Snake game I made using Python and Pygame. I built it by using python + pygame, adding features like movement, food, power-ups, obstacles, a scoring system, and different difficultys. I also added a main menu, pause screen, and game-over screen.

To play, use the arrow keys to control the snake and collect food to increase your score and grow longer. Avoid hitting the walls, pillars, or your own body, or the game will end. You can also collect power-ups to get special powers... Try to survive as long as possible and have fun! 

You can download the game from https://bluecreekdev.itch.io/snake-game
